---
name: Always check scripts before running
description: Never execute scripts or commands without explicit user approval first
type: feedback
---

Never run scripts, commands, or SQL without first showing them to the user and getting explicit approval.

**Why:** User preference — they want to review before anything executes.

**How to apply:** Always present the script/command and wait for the user to say "run it" or equivalent before using Bash or any execution tool.
